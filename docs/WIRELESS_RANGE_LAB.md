# Wireless Range Lab desktop application

The PyQt application is the experiment notebook for this project. It does not control radios directly in the current stage; it stores trial metadata and displays the summaries generated by the serial collector.

## Start the application

```powershell
cd C:\Users\manje\RBPi-2W-Tinkering\wireless_range_lab
..\.venv\Scripts\python.exe app.py
```

No PowerShell activation is required. Calling the virtual-environment Python executable directly avoids execution-policy issues.

## Create a trial

Required information includes endpoint labels, communication mode, and environment. Save a trial before starting the collector.

The app creates a unique trial ID and then enables **Copy trial ID**. Paste that ID into the collector command to link board events to the correct experiment setup.

## View results

Stopping the collector with `Ctrl+C` writes a summary automatically. In the **Saved trial summary** panel:

1. Select the trial ID.
2. Click **Refresh summaries**.
3. Review the full self-contained report: saved setup metadata followed by packet delivery, latency, goodput, and RSSI metrics.

The view is intentionally read-only. Raw NDJSON remains separate and can be recomputed into a summary at any time.

## Data privacy

Trial data and local wireless credentials are ignored by Git. Review data before sharing it because it may contain device labels, locations, timing, and environment notes.
